# A Tender

Статический сайт на Eleventy. Исходные страницы и материалы находятся в `src/`, собранный сайт — в `_site/`.

## Локально

Требуется Node.js. Установите зависимости командой `npm install`, запустите предпросмотр через `npm start`; сборка — `npm run build`.

## Структура

- `src/pages/` — страницы услуг, блога, шаблонов и контактов.
- `src/blog/posts/` — статьи Markdown; каждая статья формирует отдельную страницу.
- `src/_data/` — общие тексты и настройки.
- `src/_includes/` — общие шаблоны.
- `src/assets/` — стили, скрипты и предоставленные ресурсы.
- `src/downloads/` — реальные документы для бесплатного скачивания.

Не добавляйте неподтверждённые отзывы, публикации, документы или контактные данные. Перед публикацией материалов о закупках проверьте их актуальность. Хостинг и публикация пока не настроены.
